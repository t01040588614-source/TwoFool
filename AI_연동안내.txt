SCMAGLEV — AI(GPT) 연동 안내 (팀원용)
=====================================

※ ZIP 안에 AI UI + 코드 모두 포함되어 있습니다.

[화면 — templates 폴더]
  - templates/index.html      → 메인 "SCMagLEV AI 검색" 채팅
  - templates/dashboard.html  → 대시보드 AI 운영 어시스턴트

[백엔드 — openai_*.py]
  - openai_assistant.py   (승객·관제 AI 채팅)
  - openai_dashboard.py   (관제 안내문·인수인계 GPT 초안)
  - openai_recommender.py (승객 추천 GPT 문구)
  - openai_config.py      (AI ON/OFF 설정)

※ templates 는 "book" 폴더 안에 있어야 합니다.
  (백엔드만 따로 빼면 AI 화면이 안 나옵니다)

※ 별도 AI 파일이 없어 보이는 이유
  → .env 파일에 OPENAI_API_KEY 가 없으면 자동으로 "규칙 기반" 모드로 동작합니다.
  → API 키는 보안상 ZIP에 넣지 않았습니다. 팀 채팅/메신저로 따로 전달하세요.


■ 1) .env 설정 (필수 + AI)
--------------------------
"book" 폴더의 .env 파일에 아래를 추가:

JWT_SECRET_KEY=아무거나-긴-랜덤-문자열-32자-이상

# ↓ AI 사용 시 (팀장에게 sk-... 키 받아서 붙여넣기)
OPENAI_API_KEY=sk-여기에-팀-OpenAI-키
OPENAI_MODEL=gpt-4o-mini
OPENAI_ENABLED=auto

※ OPENAI_ENABLED=auto → Key 있으면 GPT, 없으면 규칙 기반
※ Key 넣은 뒤 run_server.bat 다시 실행 (재시작 필수)


■ 2) AI 동작 확인 방법
----------------------
[승객 페이지] http://127.0.0.1:5001/
  - 상단 배지: "AI · GPT · gpt-4o-mini" → GPT 연동 성공
  - "AI · 규칙 기반" → Key 미설정 또는 서버 미재시작

[관제 대시보드] http://127.0.0.1:5001/dashboard
  - 상단 배지: "AI · GPT 연동"
  - AI 채팅 / 인수인계 GPT 초안 / 이벤트 AI 요약 사용 가능

[서버 콘솔]
  - [SCMAGLEV] OpenAI 활성 · GPT · gpt-4o-mini  → 정상
  - [SCMAGLEV] OpenAI 미설정 · 규칙 기반 모드    → Key 없음


■ 3) AI 기능 위치
-----------------
승객 페이지
  - AI 여행 도우미 채팅
  - 열차 검색 후 GPT 추천 reason_line

관제 대시보드
  - AI 운영 어시스턴트 채팅
  - 인수인계 / 안내문 GPT 초안 생성
  - 이슈 이벤트 AI 요약


■ 4) Key 없을 때 (규칙 기반)
----------------------------
- 서버·예매·대시보드·ACK 등 핵심 기능은 모두 동작
- AI 답변/초안만 템플릿(규칙) 기반으로 생성됨
- 발표/데모 전 GPT 쓰려면 반드시 Key 설정


■ 5) 팀장에게 요청할 것
-----------------------
1. OPENAI_API_KEY (sk- 로 시작)
2. (선택) OPENAI_MODEL — 학습(파인튜닝) 모델 쓰는 경우 ft:... 값

문의 시: 화면 배지 문구 + 서버 콘솔 첫 줄 + .env에 OPENAI_API_KEY 넣었는지
